MyReciPaliPhone, beta on TestFlight

Recipes from TikTok, ready to cook.

Save a recipe from a post or any website. MyReciPal pulls out the ingredients and steps and builds the shopping list.

  • Offline firstSwiftData with seven versioned schemas and migrations.
  • Two-way syncLaravel API and PostgreSQL, conflicts settled by version.
  • On-device importApple's Foundation Models, a server model as fallback.
  • Share ExtensionSave a recipe straight from Instagram or TikTok.
How it's built
  • SwiftUI and SwiftData, offline first, with seven versioned schemas and migrations.
  • Laravel API with two-way background sync to PostgreSQL, conflicts settled by version.
  • Recipe import on the phone with Apple's Foundation Models, a server model as fallback.
  • Share Extension, so a recipe can be saved straight from Instagram or TikTok.
  • SwiftUI
  • SwiftData
  • Foundation Models
  • Laravel
  • PostgreSQL

It reads the caption or the web page. If the steps only live in the video, it won't invent them.
